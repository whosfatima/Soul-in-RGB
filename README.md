# Soul in RGB 🎨

**Just pick a color. Nothing else to see here. 👀**

Soul in RGB is a small, fun project that generates random colors and lets you explore them with a single click.

## ✨ Features

- 🎲 **Random Color Generation:** Generates a random RGB color using values between `0` and `255`.
- 🌈 **Dynamic Background:** Changes the page's background color every time you click the button.
- 📋 **Copy to Clipboard:** Copies the generated RGB color with a single click.
- 🎨 **Simple and Fun:** A tiny project made just for fun and practice.

## ⚙️ How It Works

The project uses JavaScript to generate random RGB colors and update the page dynamically.

1. **Random Numbers:** The `randomNumber()` function generates random integers between a minimum and maximum value.
2. **Color Creation:** The `CreateColor()` function combines three random numbers to create an RGB color string, representing red, green, and blue.
3. **Background Update:** When the main button is clicked, a new color is generated and applied to the page's background.
4. **Color Display:** The generated RGB value is displayed on the page so you can see which color was selected.
5. **Copy Feature:** The copy button uses the Clipboard API to copy the RGB value to your clipboard.
